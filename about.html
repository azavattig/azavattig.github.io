How I work

Start with the data that already exists

The freight savings at TL Trading came from shipment history the company already had. Most operations already have the answer somewhere in their records.

Build the tool when the spreadsheet runs out

Pavind's fleet had time windows, two shifts and trucks that fill up mid-route. That needed an optimizer, so I built one in OR-Tools and tested it against the plans the team was using.

Tie every number back to its source

DealNexa's review cites the document behind each finding, and the earnings adjustments only use figures the documents support. A number nobody can trace doesn't get used.

Show the work

Both demos on this site run on the real code, with sample data. You can break a truck down mid-route or move the LBO inputs and see what changes.
